📁 فاز ۱: تحلیل فایل (File Analysis)

۱. شناسایی نوع فایل

bash 
# با دستور file
file file.bin
file -i file.bin  # MIME type
file -k file.bin  # توضیحات کامل
file -z file.bin  # فایل‌های فشرده

# بررسی Magic Bytes (هگزادسیمال)
xxd file.bin | head -n 20
hexdump -C file.bin | head -n 20
hd file.bin | head -n 20

# Magic Bytes معروف:
# JPEG: FF D8 FF E0
# PNG: 89 50 4E 47
# PDF: 25 50 44 46
# ZIP: 50 4B 03 04
# ELF: 7F 45 4C 46
# PE: 4D 5A 90 00
# GIF: 47 49 46 38
# MP4: 00 00 00 18 66 74 79 70

# تبدیل Magic Bytes به ASCII
printf "\x89\x50\x4E\x47" # PNG
printf "\x25\x50\x44\x46" # PDF

# با binwalk (تحلیل فایل‌های جاسازی شده)
binwalk file.bin
binwalk -e file.bin  # استخراج فایل‌های جاسازی شده
binwalk -Me file.bin  # استخراج بازگشتی
binwalk -dd=".*" file.bin  # استخراج همه چیز

# آنالیز عمیق
binwalk -A file.bin  # آنالیز سیگنچر
binwalk -W file.bin  # آنالیز هگز مقایسه‌ای

۳. رمزهای کلاسیک (Caesar, Vigenere, XOR)

python 
# Caesar Cipher
def caesar(text, shift):
    result = ""
    for char in text:
        if char.isalpha():
            ascii_offset = 65 if char.isupper() else 97
            result += chr((ord(char) - ascii_offset + shift) % 26 + ascii_offset)
        else:
            result += char
    return result

# جستجوی all shifts
for i in range(26):
    print(f"Shift {i}: {caesar(text, i)}")

# XOR single-byte
def xor_single_byte(data, key):
    return bytes([b ^ key for b in data])

# جستجوی کلید
for key in range(256):
    decrypted = xor_single_byte(data, key)
    if all(32 <= c <= 126 for c in decrypted):
        print(f"Key: {key}, Result: {decrypted}")

💡 نکات طلایی پیشرفته برای CTF

  1. همیشه از strings شروع کنید: ساده اما مؤثر
  2. بیت‌ها و بایت‌ها را دستکاری کنید: گاهی flag در LSB پنهان است
  3. متادیتا را جدی بگیرید: تصاویر و اسناد حاوی اطلاعات مخفی
  4. PCAPها طلا هستند: هر بسته ممکن است حاوی اطلاعات باشد
  5. حافظه را جدی بگیرید: فرآیندهای مخفی و دستورات اجرا شده
  6. استگانوگرافی را جدی بگیرید: عکس‌ها و صداها حاوی پیام‌های مخفی
  7. کدگذاری‌ها را تشخیص دهید: Base64, Hex, ROT13, URL encode
  8. هش‌ها را بشناسید: نوع هش را تشخیص دهید و کرک کنید
  9. Slack space را چک کنید: داده‌های حذف شده در آنجا هستند
  10. مرورگرها گنجینه هستند: کوکی‌ها، تاریخچه، کلمات عبور
